Added an `I18nProvider` component to set the locale for all design system components globally. Use the `locale` prop to set the language of built-in translations strings. The optional `formattingLocale` prop enables setting a separate locale to format date, time, currency, and other numeric values and defaults to the `locale` prop. Read the new [Internationalization docs](https://circuit.sumup.com/?path=/docs/introduction-internationalization--docs) for details.
