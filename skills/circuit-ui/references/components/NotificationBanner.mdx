# NotificationBanner

<Status variant="stable" />

The notification banner component prominently communicates and promotes high-level, site-wide information to the user.

<Props of={Stories.Base} />

## When to use it

The notification banner should be used to display the global system messages or for promotions and recommendations.


## How to use it

### Variants
The notification banner component has two variants:
- **system** - for system messages, communicating topics on a global level
- **promotional** - for promotions and recommendations

### Images
Use the `image` prop to add visual context to a notification banner. Images can help make a message more noticeable, especially for promotional content or important announcements.

You can provide an image in one of two ways:
- Pass standard image properties through the `image` object, using the `ImageProps` type.
- Use one of Circuit UI’s predefined illustrations by passing an `IllustrationProps` object. See the [illustration library](Features/Illustrations/Docs) for available illustrations.

```tsx
import { NotificationBanner, type NotificationBannerProps } from '@sumup-oss/circuit-ui';

// with a source URL
function Banner(props: NotificationBannerProps) {
  return (
    <NotificationBanner {...props} image={{ src: 'https://example.com/image.png', alt: "" }} />
  )
}

// with a circuit-ui illustration
function Banner(props: NotificationBannerProps) {
  return (
    <NotificationBanner {...props} image={{ illustration: 'celebration', size: 180 } } />
  )
}
```
<Story of={Stories.CustomImage} inline={false} />

Use the `width` property to set the width of the image. The default value is `200px`.
```tsx
import { NotificationBanner, type NotificationBannerProps } from '@sumup-oss/circuit-ui';

function Banner(props: NotificationBannerProps) {
  return (
    <NotificationBanner {...props} image={{ src: 'https://example.com/image.png', alt: "", width: '120' }} />
  )
}
```

### Dismissing the banner
Make the banner dismissible by controlling its visibility with `isVisible`. Update that state in `onClose`, and provide `closeButtonLabel` so the close button is accessible.
