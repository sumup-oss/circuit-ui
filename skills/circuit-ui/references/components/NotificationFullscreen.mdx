# NotificationFullscreen

<Status variant="stable" />

The NotificationFullscreen component provides important information or feedback as part of a process flow.

## When to use

Use the NotificationFullscreen component in the following situations:
- As a confirmation/success screen.
- As an empty screen state.
- As an error screen.

## How to use

The NotificationFullscreen component is meant to be used as a standalone component. Its headline renders as a level 2 heading by default. If there is no other `h1` on the page, pass a `headline` prop as an object with the `as: "h1"` property (see Accessibility below).

You can display one or two call-to-actions (anchors or buttons) at the bottom of the NotificationFullscreen using the `actions` prop, which follows the guidelines of the [ButtonGroup](Components/Button/ButtonGroup) component.

### Image
The NotificationFullscreen component can render an image asset in 3 different manners:
- `illustration`: use one of the available illustrations from the [Illustration](Features/Illustration/Docs) library.
- `src`: A URL to an image asset.
- `svg`: An SVG element.

The image asset has a fixed height of 160px, and a maximum width of 280px, except for illustrations that have a fixed 1:1 aspect ratio.

## Accessibility

By default, the NotificationFullscreen component renders an `h2` heading element. This assumes that the component is rendered as part of a broader heading structure, on a page that already has a parent `h1` heading element.

However, the component may also be used in isolation, for example for full-screen error pages. In this case, in order to maintain an accessible heading hierarchy, the NotificationFullscreen's headline should be rendered as an `h1`. This can be done by passing the `headline` prop as an object with the `as: "h1"` property.
