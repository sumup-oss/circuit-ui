# Code

The Code component presents inline code, such as commands, file names, and variable names.

## Usage guidelines

Use Code within text to distinguish code from the surrounding content. It renders a semantic `<code>` element with a monospace font, a subtle background, and a border.

<Story of={Stories.Inline} />

Code accepts standard HTML attributes and supports custom styles through the `className` and `style` props.
